## 特長

- **話すだけで入力**: Optionキーを1回押して話し、もう一度押す（または Enter）と、直前に使っていた入力欄に貼り付けられます。
- **すべてMacの中で処理**: 音声認識は、このMacの中で完結します。音声も文字も、外には送りません。
- **話した文字が、その場で見える**: 入力欄の近くに小さなパネルが開き、認識中の文字がリアルタイムに表示されます。
- **音声・動画ファイルも文字起こし**: ファイルをドラッグして、タイムスタンプ付きで文字起こしし、txt / srt / json で書き出せます。
- **履歴**: 音声入力した文字を一覧で見られます（オフにも、消去もできます）。
- **入力できないときも安心**: 入力先が見つからないときは、文字をクリップボードに保存してお知らせします。

## 動作環境

- macOS 14 以降
- Apple Silicon（M1 以降）
- 空き容量: 約1GB（アプリ＋モデル）

## インストール

1. [最新のリリース](https://github.com/bakuuux/voqa_release/releases/tag/v0.1.4)から `Voqa-0.1.4.dmg` をダウンロードして開く
2. **Voqa** のアイコンを、横の **Applications** へドラッグ
3. Voqa を開き、画面の「**最初のセットアップ**」に沿って進める

> **初めて開くとき**: 開発元を Apple に登録していないため、警告が出ます。「システム設定 > プライバシーとセキュリティ」で「このまま開く」を選んでください。

### 最初のセットアップ（4ステップ）

| | 内容 |
|---|---|
| ① モデル | 音声認識のモデルを入れます。「ネットからダウンロード」（約0.35GB）か、手元のファイルを選びます |
| ② アクセシビリティ | キーの検出と、入力欄への貼り付けに必要です |
| ③ マイク | 音声を聞き取るために必要です |
| ④ 試す | 実際にOptionキーを押して、話してみます |

## 使い方

| 操作 | キー |
|---|---|
| 聞き取りを始める | **Option** を、単独で押して離す |
| 終了して入力する | もう一度 **Option**、または **Enter** |
| 破棄する | **Esc** |

- 開始キーは、設定で、Shift・Option・Control・Command・Fn から選べます（左右も区別できます）。
- ほかのキーと組み合わせて押したとき（`Option + 文字` など）は、反応しません。

## プライバシー

- 音声認識は、すべてMacの中で行います。
- 更新の確認とダウンロードは、「アップデート」のボタンを押したときだけ行います。自動では確認しません。送るのは、取得の要求だけで、音声や文字は含まれません。
- アップデートは、アプリの中から、ボタン1つで行えます。ダウンロードしたファイルは、開発元の署名と、ハッシュを確認してから、入れ替えます。
- 履歴は、このMacの中だけに保存されます。設定でオフにでき、いつでも消去できます。

## ファイルの確認

ダウンロードした DMG が、配布したものと同じかを、確かめられます。

```
shasum -a 256 Voqa-0.1.4.dmg
```

出た値が、[リリースのページ](https://github.com/bakuuux/voqa_release/releases/tag/v0.1.4)に書かれた SHA-256 と同じなら、問題ありません。

## 困ったときは

| 症状 | 対処 |
|---|---|
| Optionを押してもパネルが出ない | アクセシビリティの許可を確認してください。Voqa の「セットアップ状況」に、足りない項目が出ます |
| 文字が入らない / 音声が届かない | マイクの許可を確認してください |
| 入力欄に貼り付けられない | 結果はクリップボードに保存されます。⌘V で貼り付けてください |
| 更新したら、許可が外れた | アプリを入れ直すと、アクセシビリティとマイクの許可を、付け直す必要があります |

## ご注意

- **ベータ版です**。動作が不安定だったり、環境によって、うまく動かなかったりすることがあります。機能や画面は、今後変わる場合があります。
